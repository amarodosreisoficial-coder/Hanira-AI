# Documentacao Hanira AI

Base documental tecnica do repositorio.

## Legenda de status

- `Implementado`: descreve comportamento ou estrutura confirmados no codigo.
- `Planejado`: descreve direcao futura ja assumida como alvo.
- `Proposto`: descreve desenho inicial ainda sujeito a refinamento.
- `Em revisao`: documento consolidado, mas ainda dependente de revisao humana
  antes do versionamento.
